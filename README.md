# 棋境 · Chess Atelier

一款支持棋谱学习、人机对弈和复盘分析的国际象棋网页。

**[在线使用](https://827853487.github.io/chess-atelier/)** · 无需安装，Stockfish 在访问者设备上运行。

## 功能

- **人机对弈**：Stockfish 六档难度，支持悔棋、翻转视角和四种升变选择。
- **局势分析与复盘**：实时胜／和／负估计、候选着法、提示箭头，以及逐着评价和棋盘角标；关闭分析后展示棋间短句。
- **棋谱学习**：开局、大师对局（含卡斯帕罗夫合集）和专题训练，支持逐着浏览、着法定位与自动播放。
- **锁定与试走**：保留当前局面自由推演，或从当前步切换到人机对弈；保留此前着法，可快速返回锁定位置。
- **棋谱管理**：PGN 导入、自定义合集、星标收藏，自动保存最近 20 局，支持独立保存和标准 PGN 导出。
- **外观与操作**：六套主题、经典／立体／极简／抽象四种棋子，配有走子动画与音效，适配电脑和手机。
- **古典音乐**：按时期随机播放本地及 Wikimedia Commons 录音，支持进度控制、真实频谱、曲名复制和来源查看。

## 使用与数据

对弈与分析不依赖云端引擎。收藏、个人棋谱和最近对局保存在当前浏览器中，刷新后保留，不跨浏览器或网址同步；重要棋谱建议导出 PGN 备份。在线曲库需要联网。

本机版需 Python 3.10+ 和原生 Stockfish，运行 `启动网站.bat`。安装、构建与部署步骤见下方文档。
