# 棋境 · 本地 Stockfish 版

源码仓库：[827853487/chess-atelier](https://github.com/827853487/chess-atelier)（公开，可直接浏览和下载源码）。正式访问地址：[GitHub Pages](https://827853487.github.io/chess-atelier/)。原 Sites 地址保留为镜像。

另提供无需安装的公网浏览器构建：Stockfish 在访客设备上运行。GitHub 源码、静态导出、上线和更新方式见 [公网部署说明](公网部署说明.md)。源码仓库不包含 Windows 安装二进制；原工作目录中的本机安装继续保留。

打谱、人机对弈和实时分析均在本机运行。已内置你下载的 **Stockfish 19**（`engines/stockfish.exe`）；没有云分析、自制棋力引擎或固定开局提示作为回退。

## 启动

1. 安装 Python 3.10 或更新版本，双击 `启动网站.bat`。
2. 首次启动如缺少 `chess` 棋规库，会通过当前 Python 的 pip 安装一次；之后对弈、分析和内置棋谱可断网使用。本次开发环境已安装。
3. 保持启动窗口开启。首次启动优先使用端口 8765；若 Windows 保留或占用该端口，会选择 18765 等备用端口，并将可用端口记入 `data/server-port.json`。以后沿用此地址，以便重新访问浏览器中保存的棋谱。修改软件后，先关闭旧的启动窗口，再重新启动。

也可手动运行 `python -m pip install chess`，再运行 `python serve.py`，访问 `http://127.0.0.1:8765`。局域网访问请使用 `启动局域网.bat`。直接双击 HTML 无法运行本地 Stockfish。

已收录四时期共 16 首授权本地录音（约 53 分钟），曲目可离线播放；自动连接的在线曲库扩充和公开棋谱下载仍可能联网；棋局、局面和分析请求不发送到外部服务。无需 Lichess 密钥。

## 对弈与分析

| 难度 | Stockfish 目标强度 | 每着思考时间 |
| --- | --- | --- |
| 入门 | Elo 1320 | 350 ms |
| 休闲 | Elo 1600 | 500 ms |
| 进阶 | Elo 1900 | 700 ms |
| 高手 | Elo 2200 | 1000 ms |
| 大师 | Elo 2600 | 1400 ms |
| 全力 | 关闭限强，Skill Level 20 | 2200 ms |

限强使用引擎的 `UCI_LimitStrength` / `UCI_Elo`，不会将 Elo 与 Skill Level 混合设置。启动时读取引擎实际 Elo 范围；本机 Stockfish 19 为 1320–3190。Elo 是引擎目标值，实际表现受设备、思考时间影响，并非平台等级分。

- 对弈与分析各用独立进程，单进程 1 线程、64 MB Hash；电脑落子不必等待局面分析结束。
- Stockfish 支持局面评估、胜和负估计与候选变化，不直接生成自然语言讲解。界面只保留紧凑的 Stockfish 开关栏、顶部胜和负进度条和三条着法建议；版本号、独立深入分析入口、大号分值、深度及上一步评价已从界面移除。
- 实时分析每个局面搜索约 1.2 秒，始终全强度。进度条使用主题色、扩展色和中性色分别表示白胜、黑胜、和棋，百分比取整且合计为 100%。数值在本轮搜索完成时更新一次，宽度平滑过渡；等待期间淡化上次估计，不显示搜索中间值。概率来自 Stockfish 自我对弈模型，不代表玩家的实战胜率。
- 点击候选着法只画箭头；常驻标题为「局势分析」，开关为「实时分析」。关闭后数据在约 0.12 秒内淡出，显示本地棋句或走棋提示；双击、回车或空格可换一句。英文单独换行展示括号中的中文翻译，全部使用斜体。切换局面会取消旧请求，缓存包含历史记录，支持重复局面判定。
- 引擎异常会显示原因并停止电脑落子；“重新连接 / 重试”可恢复，不会改用其他引擎。

棋子选项依次为「经典、雅致、简约」，经典为默认风格；有效的已保存个人选择继续保留。三种风格的白子均使用实心近白填充，搭配各主题的深色描边，在六种棋盘配色的深浅格上均能辨认。

设置中的配色约用 0.32 秒渐变切换；新主题与棋子样式会先完成本地图片解码，再统一替换，避免空白或备用图形闪现。棋子样式切换用约 0.48 秒的同步交接动画，旧图先在原格中心缩小至 0，再由新图从同一中心放大至正常尺寸；两段各约 0.24 秒，完成时不恢复旧图。对局、复盘和翻转棋盘后均可切换，不重置着法或取消电脑思考；连续快速选择时以最后一次为准，系统减少动态效果时直接切换。

打谱和对弈都保留放映按钮，播放状态使用浅主题色。先点击着法记录中的某一步，再点击播放，就从该位置放映到启动时已有的最后一着；已经在末尾时会从头重播。放映可随时暂停，手动走棋、跳步、重开或切换模式会停止放映。对弈放映期间暂停电脑思考，到达原终点后恢复对弈；迟到的旧引擎回复会被忽略。翻转棋盘继续保留交换用户与电脑执棋颜色的行为。

## 棋谱记录、保存与导出

打谱模式显示「棋谱着法」，可点击任意一着回放，不显示导出和保存按钮。对弈模式显示「着法记录」，提供“导出 PGN”和“保存棋谱”。保存存入当前浏览器的本地棋谱库；浏览器存储不可用时自动下载 PGN。文字输入框以外的区域不显示文本插入光标。

导出为标准 **PGN（Portable Game Notation）** `.pgn` 文件：七项标准标签 `Event / Site / Date / Round / White / Black / Result`、SAN 着法、回合编号和一致的终局结果。采用 UTF-8 文本，保留导入棋谱的棋手、日期、赛事、ECO 等元数据；非标准起始局面包含 `SetUp` 和 `FEN`，支持黑方先行及任意起始回合。将军、将死、王车易位、吃过路兵和各种升变均可记录。

导出的是当前棋谱的完整主线，回放到中间不会截断；从中间续走会保留前面的着法，并以新主线取代后续记录。导出不包含原始 PGN 的文字注释或嵌套变例。

## 棋谱分类与彩蛋

棋谱库分为「开局学习」「大师对局」「专题训练」「我的棋谱」四个入口。没有“全部”选项；点击分类时选中第一个合集，只有一个合集时不显示下拉箭头。导入和管理按钮只在「我的棋谱」显示。列表在空合集和完整合集之间切换时保持稳定高度。

棋谱右侧的星星可收藏或取消收藏；在「我的棋谱 → 星标收藏 ★」统一查看。收藏不会搬动原棋谱，也不会开始回放，刷新后保留；清除浏览器站点数据会同时移除收藏和个人保存记录。「导入」和「我的保存」合并为同一个「我的棋谱」合集，兼容已有记录；自定义合集继续保留。

增补库目前有 61 个合集、6,072 条内容。本轮增加卡斯帕罗夫 2,126 盘、其他九位大师精选 1,400 盘，以及 26 类共 776 道分级练习、卡帕布兰卡《国际象棋基础》公开整理谱 81 章。大师对局默认进入卡斯帕罗夫合集，课程按章节、练习按题目等级分排序；“学习与来源”可查看覆盖范围和参考。课程中的 7 个纯局面示例可直接查看引擎分析，其余内容有参考主线；未宣称包含原书全部文字讲解、所有分析分支或自动判题。

此前的 960 盘开局实战、570 盘经典赛事、30 条伦敦示范片段、6 个残局研究、120 个实战残局续篇和 3 盘短局与将杀继续保留。专题、赛事和棋手合集会交叉，条目数不是互不重复的比赛总数。来源与文件校验见 `data/library-sources.json`、`data/LIBRARY_SOURCES.md`，学习顺序与练习方式见 [学习目录](data/CURRICULUM.md)。新增大师对局与分级题采用稳定题目 ID 或棋谱指纹；旧内容的收藏标识保持兼容。增补文件以校验值区分浏览器缓存，更新后可读取最新内容。

Logo 连点间隔不超过约 1.4 秒：第 6 下出现浅主题色托盘上的橙子，第 12 下同时保留橙子并出现深主题色托盘上的茉莉花；茉莉花托盘有背景色浅边框。继续点击会共同顺延展示时间，停止后约 5–10 秒沿出现路径同步收回。出现和收回均为 0.3 秒；收回预先排到浏览器动画时间线上，不依赖下一次点击触发。

后续功能优先级见 [改进方向](改进方向.md)。

完整功能、代码职责、状态流转、存储结构、接口、动画时序、题库维护、验证步骤与已知限制见 [功能与实现维护手册](功能与实现维护手册.md)。

## 开发与验证

前端源码修改后运行 `python build_bundle.py` 更新浏览器实际加载的 `app.bundle.js`。

```text
node --test tests/records.test.cjs tests/library.test.cjs tests/chess-notes.test.cjs
node tests/validate-library.cjs
python -m unittest discover -s tests -p test_engine.py -v
python serve.py --check
```

浏览器集成测试：先安装 Playwright 并准备 Microsoft Edge，启动本地服务后运行 `node tests/browser-smoke.cjs`。可用 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径，`CHESS_TEST_URL` 指定服务地址（默认 `http://127.0.0.1:18765`）。截图、下载棋谱和结果输出到 `test-results/`。

分类与连点彩蛋：`node tests/library-and-logo.cjs`。收藏、离线数据与布局稳定性：`node tests/library-favorites.cjs`。分析、关闭短句、模式区别与对弈：`node tests/revised-workflow.cjs`。胜率稳定性、主题色及无输入自动收回：`node tests/quiet-analysis.cjs`。

旧个人合集合并、开局实战、结束提示定位和菜单稳定性：`node tests/library-refinements.cjs`。将军时保留柔和红框；无效应将时短促闪烁一次（180 ms），合法解将后撤去红框：`node tests/check-response.cjs`。

外观切换的逐帧检查、延迟图片加载、原位缩放、连续选择、对局不中断和减少动态效果：`node tests/appearance.cjs`。

棋子顺序为经典 Cburnett、拟真 Maestro、极简 Mpchess、抽象 Totoy，默认经典。均来自 Lichess 官方原图，保留造型与原始描边，按六套主题生成静态配色，来源及各自许可见 [棋子说明](assets/pieces/README.md)（Maestro 限非商业用途）。图形与许可校验：`python tests/piece_assets.py`；六主题视觉检查：`node tests/classic-pieces.cjs`；重建主题：`python scripts/build_piece_themes.py`。

对弈从选定着法放映、暂停/继续、引擎暂停恢复及旧回复隔离：`node tests/playback.cjs`。个人棋谱删除失败保留、删除成功持久化、设置弹窗展开状态：`node tests/storage-failure.cjs`。

大师新增合集、教材纯局面和黑方先行分级题的离线打开、放映与收藏：`node tests/master-training.cjs`。

PGN 格式依据：[PGN Specification and Implementation Guide](https://www.saremba.de/chessgml/standards/pgn/pgn-complete.htm)。Stockfish 参数说明见 `engines/Stockfish-UCI.md`，来自你的官方压缩包；许可和来源见 `ATTRIBUTION.md`。

新棋局约用 0.8 秒完成开盘：旧棋子作为一个网格整体收拢到中心消失，再由四周到内侧分批、短距离入场。支持任意当前局面和翻转视角；电脑先行等入场完成才落子，点击棋盘可直接结束入场并继续操作，快速重开会清理前一轮。验证：`node tests/opening.cjs`。

## 复盘、提示与音乐

打谱可从起始局面开启「复盘分析」；对弈结束后也可开启。点击后才加载 Stockfish，先显示简短进度，在局势分析框内逐步补全本步评价、棋子右上角的着法标记和参考线。角标等走棋动画完成后渐显；复盘期间隐藏普通候选列表，显示对应评价、当前可走的参考箭头与简短文字。实时分析开关名称保持不变。关闭即停止复盘并返回棋谱浏览；同一未改动棋谱再次打开可复用结果。参考标记来自限时引擎计算，不是绝对棋力评分。

关闭分析时显示的棋句池有 248 条（含 16 条核验短引语），采用整轮不重复的随机顺序并保存进度；引语换行显示出处链接，外文附自译。

音乐默认使用 Wikimedia Commons 授权录音的 16 首本地 MP3，四时期各 4 首，后台准备三首候选；点击时期即随机播放。乱序时「上一首」同样选新曲，顺序时可回到前一首。后台自动按时期分页扩充 Commons 录音，界面不提供曲库开关、播放列表或进度条下方的网页提示；署名行链接到当前录音来源与许可。在线播放与预载仍受网络、浏览器和来源站限制；大于 8 MB 的在线录音直接流式播放。逐曲署名、许可和转码说明见 [音乐来源](data/MUSIC_SOURCES.md)，开放目录选择见 [在线曲库说明](data/ONLINE_MUSIC.md)。

验证：`node tests/review.cjs`、`node tests/media-ui.cjs`、`node --test tests/music-order.test.cjs`。GitHub Actions 在 main 更新时构建并部署 GitHub Pages，见 `.github/workflows/check.yml`。

点击播放器曲名可复制“作曲家 - 乐曲名”，显示短暂的“已复制”悬浮提示；界面曲名移除开头重复的作曲家，不使用文本输入框或选择状态。

打谱模式仅供浏览，点击棋子会提示使用箭头，不改动棋谱或打断正在播放的走子动画。前进/回退保留走子动画；换谱、翻转采用居中收拢和分批展开，翻转保留原局面与查看步数。复盘文字随走子渐显，角标到达后仍用 220 ms 入场、150 ms 退场，参考箭头交替淡入/淡出。短句仅在重置/换谱/翻转时自动更新，仍支持双击手动换句。
